# ORBITAL — Devlog

## Goal
Build a tiny, replayable satellite-survival game in Microsoft Excel using VBA, without a game engine.

## Core gameplay
- Three orbital lanes
- Lane switching
- Incoming space debris
- Energy pickups and scoring
- Increasing difficulty
- Collision and restart loop
